# FPGAs
Contains FPGA Labs and Projects for ECSE 317.

## Lab 1
Lab 1 focuses on the end-to-end RTL-to-FPGA flow by implementing and verifying an unpipelined and 3-stage pipelined datapath for $y=(a\times b)+(c\times d)+e$, then comparing timing (WNS/Fmax), resource usage, and latency/throughput trade-offs.
